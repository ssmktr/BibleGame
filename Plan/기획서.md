## 게임 종류

- 사도신경_주기도문_순서맞추기
- 구약_신약_순서맞추기

## 게임 화면
- 처음 화면에 시작하기 버튼 배경은 귀여운 중,고 등학생들이 교회에서 웃고 있는 배경으로 합니다.
- 게임 시작 버튼을 만듭니다.
- 게임 시작 버튼을 누르면 게임 종류 선택 화면으로 갑니다.
- 게임 종류는 위에 리스트를 참고해서 버튼을 생성합니다.
- 각 게임 종류 버튼을 누르면 해당 게임을 시작합니다.
