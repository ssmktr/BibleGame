# 기획서 PRD : 성경 게임 - 시작 화면 / 게임 선택 화면

> 본 문서는 [기획서.md](../기획서.md) 를 기반으로 작성된 시작(Start) 영역에 대한 제품 요구사항 정의서(PRD) 입니다.

## 1. 개요 (Overview)
교회에서 중·고등학생들이 성경과 주요 기도문에 친숙해질 수 있도록 만든 웹 기반 미니게임 모음입니다.
앱 진입 시 첫 화면(시작 화면)과, 시작 버튼을 누른 뒤 보이는 게임 종류 선택 화면을 정의합니다.

## 2. 목적 (Goals)
- 학생들이 부담 없이 들어와 게임을 빠르게 시작할 수 있도록 직관적인 진입 흐름을 제공한다.
- 한 화면에서 어떤 게임이 있는지 한눈에 확인하고, 한 번의 클릭/터치로 게임을 시작할 수 있도록 한다.
- 교회 분위기에 어울리는 따뜻하고 친근한 톤앤매너를 유지한다.

## 3. 타깃 사용자 (Target Users)
- 주 대상 : 중학생 ~ 고등학생
- 보조 대상 : 교회학교 교사, 부모
- 사용 환경 : PC 브라우저 및 모바일 브라우저 (반응형)

## 4. 화면 구성 (Screens)

### 4.1 시작 화면 (Start Screen)
| 항목 | 내용 |
|---|---|
| 경로 | `/` |
| 배경 | 교회에서 웃고 있는 귀여운 중·고등학생들의 일러스트/이미지 |
| 타이틀 | "성경 게임" |
| 핵심 UI | "게임 시작" 버튼 (큰 사이즈, 화면 중앙 또는 하단 중앙 배치) |
| 동작 | 버튼 클릭 시 게임 종류 선택 화면(`/select`)으로 이동 |

#### 시각/톤 요구사항
- 배경 이미지는 화면 전체를 채우되, 텍스트/버튼 가독성을 위해 어두운 오버레이 또는 그라데이션을 얹는다.
- 폰트는 둥글고 친근한 느낌의 한글 폰트를 사용한다.
- 버튼은 충분히 크게(터치 영역 최소 48x48px) 만들고, 호버/탭 시 자연스러운 피드백을 준다.

### 4.2 게임 종류 선택 화면 (Game Select Screen)
| 항목 | 내용 |
|---|---|
| 경로 | `/select` |
| 타이틀 | "게임을 골라보세요" |
| 핵심 UI | 게임 종류별 버튼 카드 리스트 |
| 동작 | 카드 클릭 시 해당 게임 화면으로 이동 |

#### 표시할 게임 카드
1. **사도신경/주기도문 순서 맞추기** → 클릭 시 `/games/creed-prayer` 로 이동 — 세부 사양은 [사도신경_주기도문_순서맞추기_PRD.md](사도신경_주기도문_순서맞추기_PRD.md) 참고
2. **구약/신약 순서 맞추기** → 클릭 시 `/games/old-new` 로 이동 — 세부 사양은 [구약_신약_순서맞추기_PRD.md](구약_신약_순서맞추기_PRD.md) 참고

> 향후 신규 게임이 추가될 경우, 이 화면의 카드 리스트에 항목을 추가하는 방식으로 확장한다.

#### 카드 구성 요소
- 게임 제목
- 한 줄 설명 (예 : "성경 66권의 순서를 맞춰보세요")
- 대표 아이콘 또는 일러스트 (선택)

## 5. 사용자 흐름 (User Flow)

```
[시작 화면]
   │  "게임 시작" 클릭
   ▼
[게임 종류 선택 화면]
   │  게임 카드 클릭
   ▼
[해당 게임 화면]  ← 별도 PRD 참고
```

## 6. 기능 요구사항 (Functional Requirements)
- FR-1. 시작 화면 진입 시 배경 이미지가 화면을 채워 표시되어야 한다.
- FR-2. "게임 시작" 버튼을 누르면 게임 종류 선택 화면으로 라우팅된다.
- FR-3. 게임 선택 화면에는 기획서에 정의된 게임 목록이 모두 카드로 노출된다.
- FR-4. 각 카드 클릭 시 해당 게임 페이지로 라우팅된다.
- FR-5. 모든 화면은 모바일(세로), 태블릿, 데스크탑에서 정상적으로 보여야 한다.
- FR-6. 뒤로가기 버튼 또는 로고 클릭으로 시작 화면으로 돌아갈 수 있어야 한다. (선택 화면 이후)

## 7. 비기능 요구사항 (Non-Functional Requirements)
- 첫 페이지 LCP(Largest Contentful Paint) 2.5초 이내를 목표로 한다. (배경 이미지 최적화 필요)
- 키보드 Tab 이동 및 Enter 입력으로도 버튼/카드를 사용할 수 있어야 한다(접근성).
- 색상 대비는 WCAG AA 수준 이상을 만족한다.

## 10. 제작 순서 (Build Order)

[기획서.md](../기획서.md) 의 "제작" 섹션에 따라 다음 순서로 진행한다.

### Phase 1 — 본 문서(기획서_PRD.md) 기반 제작
시작 화면과 게임 종류 선택 화면을 먼저 만든다.
1. 라우팅 골격 구축 (`/`, `/select`)
2. 시작 화면 레이아웃 + 임시 배경 이미지 + "게임 시작" 버튼 동작
3. 게임 선택 화면 레이아웃 + 카드 컴포넌트 (사도신경/주기도문, 구약/신약 2개)
4. 두 게임 페이지 라우트 스텁 생성 (placeholder — 클릭 시 빈 페이지로 이동만 되도록)
5. 배경 이미지 최종본 적용 및 반응형/접근성 점검

> Phase 1 완료 기준 : 사용자가 시작 화면 → 게임 선택 화면 → 각 게임 placeholder 페이지까지 정상적으로 이동할 수 있다.

### Phase 2 — 게임별 PRD 기반 제작
각 게임의 세부 PRD 문서를 참고해 placeholder 페이지를 실제 게임으로 구현한다.
1. [사도신경_주기도문_순서맞추기_PRD.md](사도신경_주기도문_순서맞추기_PRD.md) 참고하여 `app/games/creed-prayer` 구현
2. [구약_신약_순서맞추기_PRD.md](구약_신약_순서맞추기_PRD.md) 참고하여 `app/games/old-new` 구현

> Phase 2 시작 전 선행 작업 : 두 세부 PRD 문서가 아직 비어있으므로 먼저 작성 필요.
