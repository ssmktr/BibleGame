# 사도신경 / 주기도문 순서 맞추기 PRD

> 본 문서는 [사도신경_주기도문_순서맞추기.md](../사도신경_주기도문_순서맞추기.md) 기반의 세부 PRD 입니다.
> 상위 흐름(시작 화면 → 게임 선택 화면)은 [기획서_PRD.md](기획서_PRD.md) 를 참고하세요.

## 1. 개요 (Overview)
사도신경 또는 주기도문의 각 문장을 카드로 만들어 무작위로 섞은 뒤, 드래그 앤 드롭으로 올바른 순서대로 맞추는 미니게임입니다. 클리어까지 걸린 시간을 기준으로 랭킹에 등록할 수 있습니다.

## 2. 라우팅 / 경로
- 게임 진입 : `/games/creed-prayer`
- 게임 플레이 : `/games/creed-prayer/play?type=creed | prayer`
- 랭킹 : `/games/creed-prayer/ranking`

## 3. 화면 구성 (Screens)

### 3.1 게임 초기 화면 (Entry)
| 항목 | 내용 |
|---|---|
| 위치 | `/games/creed-prayer` |
| 중앙 UI | **사도신경 시작** 버튼, **주기도문 시작** 버튼, **랭킹** 버튼 (3개) |
| 상단 우측 | 게임 종류 선택 화면(`/select`)으로 이동하는 버튼 |
| 상단 우측 동작 | 클릭 시 "정말 가시겠습니까?" 확인 팝업 → "예" 선택 시 `/select` 로 이동 |

### 3.2 게임 플레이 화면 (Play)
| 항목 | 내용 |
|---|---|
| 위치 | `/games/creed-prayer/play?type=...` |
| 상단 중앙 | 타이머. 진입 시 0.00초부터 카운트업 (랭킹 등록용 데이터) |
| 상단 우측 | 게임 종류 선택 화면 이동 버튼 (확인 팝업 동일) |
| 본문 | 선택한 문서(사도신경 또는 주기도문)의 각 문장을 카드로 만들어 **랜덤하게 섞어 세로로 나열** |
| 카드 동작 | 위/아래로 드래그 & 드롭. **두 카드의 위치를 서로 교환(swap)** |
| 하단 | **제출하기** 버튼 |

### 3.3 결과 처리 (Submit)
- 제출하기 클릭 시 각 카드가 정답 위치인지 채점하여 **맞은 카드는 정답 표시(예 : 초록)**, **틀린 카드는 오답 표시(예 : 빨강)** 를 한다.
- **부분 정답**(전체가 정답이 아닌 경우) : 화면 이동 없이 사용자가 계속 카드를 옮겨 다시 제출할 수 있다. 타이머는 계속 흐른다.
- **전체 정답** : 닉네임 입력 팝업을 띄운다.
  - 닉네임 입력 후 **완료** 버튼을 누르면 타이머를 정지하고 랭킹 화면(`/games/creed-prayer/ranking`)으로 이동한다.
  - 랭킹 등록 성공/실패 여부를 토스트 또는 안내 메시지로 표시한다.

### 3.4 랭킹 화면 (Ranking)
| 항목 | 내용 |
|---|---|
| 위치 | `/games/creed-prayer/ranking` |
| 구성 | 사도신경 / 주기도문 **각각의 랭킹 탭(또는 분리된 표)** 을 함께 노출 |
| 페이지네이션 | **10행 × 3페이지 = 총 30개** 등록 가능 |
| 정렬 | 클리어 소요 시간 **오름차순** (작을수록 상위 랭크) |
| 표시 컬럼 | 순위 / 닉네임 / 플레이 시간 (mm:ss.ss) |
| 상단 우측 | 게임 종류 선택 화면 이동 버튼 |

## 4. 게임 데이터 (Content)

### 4.1 사도신경 (총 9문장)
1. 나는 전능하신 아버지 하나님, 천지의 창조주를 믿습니다
2. 나는 그의 유일하신 아들, 우리 주 예수그리스도를 믿습니다
3. 그는 성령으로 잉태되어 동정녀 마리아에게서 나시고
4. 본디오 빌라도에게 고난을 받아 십자가에 못 박혀 죽으시고
5. 장사된 지 사흘 만에 죽은 자 가운데서 다시 살아나셨으며
6. 하늘에 오르시어 전능하신 아버지 하나님 우편에 앉아 계시다가
7. 거기로부터 살아 있는 자와 죽은 자를 심판하러 오십니다
8. 나는 성령을 믿으며, 거룩한 공교회와 성도의 교제와
9. 죄를 용서받는 것과 몸의 부활과 영생을 믿습니다

### 4.2 주기도문 (총 9문장)
1. 하늘에 계신 우리 아버지
2. 아버지의 이름을 거룩하게 하시며
3. 아버지의 나라가 오게 하시며
4. 아버지의 뜻이 하늘에서와 같이 땅에서도 이루어지게 하소서
5. 오늘 우리에게 일용할 양식을 주시고
6. 우리가 우리에게 잘못한 사람을 용서하여 준 것같이
7. 우리 죄를 용서하여 주시고
8. 우리를 시험에 빠지지않게 하시고 악에서 구하소서
9. 나라와 권능과 영광이 영원히 아버지의 것입니다

## 5. 기능 요구사항 (Functional Requirements)
- FR-1. 초기 화면에서 사도신경/주기도문/랭킹 3개 버튼을 노출한다.
- FR-2. 게임 진입 시 선택한 문서의 문장 배열을 **균등 분포로 랜덤 셔플**한다. (단, 우연히 정답 순서가 나오면 다시 셔플)
- FR-3. 상단 중앙 타이머는 게임 플레이 화면 진입과 동시에 0부터 동작하며, 0.01초 또는 0.1초 단위로 갱신한다.
- FR-4. 카드는 마우스/터치 모두에서 드래그 가능해야 하며, **두 카드를 서로 swap** 한다.
- FR-5. 상단 우측 "나가기" 버튼 클릭 시 확인 팝업을 띄우고, "예"를 선택해야만 `/select` 로 이동한다. 그 외의 경우 현재 상태(순서, 타이머)는 유지한다.
- FR-6. 제출 시 각 카드의 정답/오답을 시각적으로 표시한다.
- FR-7. 전체 정답이 아닐 경우 게임은 그대로 진행되며 타이머도 계속 흐른다.
- FR-8. 전체 정답 시 닉네임 입력 팝업을 띄우고, 완료 버튼 클릭 시 타이머를 멈춘 후 랭킹 등록을 시도한다.
- FR-9. 랭킹은 사도신경/주기도문 **각각 30개**까지 저장한다. 31번째 시도부터는 기존 랭킹의 최하위보다 빠를 때만 등록되고, 최하위는 밀려난다.
- FR-10. 랭킹 화면은 10행 × 3페이지 페이지네이션을 지원한다.

## 6. 데이터 / 저장
- 랭킹 저장은 **localStorage** 를 1차 저장소로 사용한다.
  - 키 예시 : `ranking:creed-prayer:creed`, `ranking:creed-prayer:prayer`
  - 각 항목 : `{ rank?: number, nickname: string, timeMs: number, createdAt: ISOString }`
- 닉네임 길이는 1~10자, 공백 트리밍 후 비어있으면 등록 불가.

## 7. UX / 접근성
- 카드는 충분히 큰 터치 영역(최소 56px 높이)을 확보한다.
- 드래그 외에도 **카드 위/아래 이동 버튼(▲ ▼)** 을 옵션으로 제공해 키보드/터치 접근성을 보강한다. (구현 우선순위 낮음)
- 색각 보조 : 정답/오답 표시는 색상 외에 아이콘(✓ / ✗)을 함께 사용한다.

## 9. 기술 스택 메모
- 드래그 & 드롭 : `@dnd-kit/core` + `@dnd-kit/sortable` 권장 (모바일/접근성 지원 우수). 또는 React 19 기본 HTML5 DnD.
- 상태 관리 : 페이지 단위 `useState` 로 충분, 전역 상태 라이브러리 불필요.

## 10. 오픈 이슈
- 카드 swap 방식이 맞는지, 일반적인 "drag to insert(삽입)" 방식이 더 자연스러울지 사용자 테스트 필요. (현재 기획서는 swap 명시)
- 부분 정답 시 틀린 카드만 다시 섞을지, 그대로 둘지? (현재 기획 : 그대로 두고 사용자가 직접 수정)
- 랭킹 저장소를 추후 서버(예: Firebase, Supabase)로 옮길 가능성 고려.
